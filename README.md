### My take on AI (LLM) usage

Recent advancements in generative AI have without a doubt made it easier than ever to arrive at solutions for formerly mentally challenging problems. My goal with programming however is not to have a solution but finding the solution in itself is the goal and having a mental image of what im doing or learning. With that said I mostly manually code and like to be precise in a formal language rather than ask a computer program for a solution to my problems in human language.
